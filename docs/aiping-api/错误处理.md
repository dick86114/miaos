# 错误处理 API 文档

## 错误码

| 错误码 | 说明 |
|--------|------|
| 400 | 参数异常 |
| 401 | 鉴权失败 |
| 402 | 所调用的模型为付费模型且余额 <= 0 的情况 |
| 404 | 模型资源不存在 |
| 405 | 请求方法（GET / POST / PUT / DELETE 等）不被允许 |
| 408 | 来自负载均衡，服务器等待客户端发送请求数据超时 |
| 413 | 发送的请求体过大，超过模型处理上限 |
| 422 | 参数错误（模型不在标准目录、input 为空、策略冲突、过滤后无候选等） |
| 429 | 达到了账户的最大访问频率限制 |
| 499 | 来自负载均衡，客户端在服务器还没返回响应前，主动关闭了连接 |
| 500 | 服务异常 |
| 502 | 来自负载均衡，服务器作为网关，从上游收到了无效/异常响应 |
| 503 | 服务器繁忙，稍后重试 |
| 504 | 来自负载均衡，服务器作为网关或代理，等待上游服务响应超时 |
