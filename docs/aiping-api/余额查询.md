# 余额查询 API 文档

## 1. 余额查询

接口地址：`https://aiping.cn/api/v1/user/remain/points`

**Authorization 需要传 apikey**

### 1.1 认证

**Authorization**

```
Bearer apikey
```

在 Header 添加参数 `Authorization`，其值为在 `Bearer` 之后拼接 apikey

示例：
```
Authorization: Bearer QC-db0...****
```

### 1.2 返回格式

#### 顶层字段

| 字段 | 类型 | 必填 | 描述 |
|------|------|------|------|
| code | number | 是 | 响应状态码 |
| data | Data | 是 | 余额数据对象 |
| msg | string | 是 | 响应消息 |

#### Data（余额数据对象）

| 字段 | 类型 | 必填 | 描述 |
|------|------|------|------|
| gift_remain | number | 是 | 赠送余额，单位元 |
| recharge_remain | number | 是 | 充值余额，单位元 |
| total_remain | number | 是 | 总余额，单位元 |

### 返回示例

```json
{
  "code": 0,
  "msg": "OK",
  "data": {
    "gift_remain": 10.5,
    "recharge_remain": 89.5,
    "total_remain": 100.0
  }
}
```
