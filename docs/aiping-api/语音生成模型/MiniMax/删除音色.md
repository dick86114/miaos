# MiniMax 删除音色 API 文档

## 接口简介

使用本接口可删除指定 `voice_id` 的音色。

可删除范围：仅支持删除以下两类音色：
1. 音色快速复刻（Voice Cloning）生成的音色
2. 音色设计（Voice Generation）生成的音色

**系统音色不可删除。**

> 注意：删除后，该 `voice_id` 将无法再次使用，请确认后再操作。

## 请求地址与鉴权

| 项目 | 说明 |
|------|------|
| 请求方法 | POST |
| 请求地址 | `/v1/audio/minimax/voices/delete` |
| Content-Type | `application/json` |
| 鉴权方式 | `Authorization: Bearer ***` |

## 请求参数

请求体为 `application/json`。

### 主请求体

| 参数名 | 类型 | 必填 | 说明 | 取值范围/格式 |
|--------|------|------|------|----------------|
| voice_type | string | 是 | 要删除的音色类型 | `voice_cloning`（快速复刻）/ `voice_generation`（文生音色） |
| voice_id | string | 是 | 要删除的音色 ID（与 **查询可用音色** 返回的 `voice_id` 一致） | - |

## 请求示例

### cURL

```bash
curl -X POST "https://aiping.cn/api/v1/audio/minimax/voices/delete" \
  -H "Authorization: Bearer ***" \
  -H "Content-Type: application/json" \
  -d '{
    "voice_type": "voice_cloning",
    "voice_id": "yanshang11123"
  }'
```

### 删除文生音色

```json
{
  "voice_type": "voice_generation",
  "voice_id": "ttv-voice-2025082011321125-2uEN0X1S"
}
```

## 响应格式

### 成功响应（application/json）

```json
{
  "voice_id": "yanshang11123",
  "created_time": "2025-10-15",
  "base_resp": {
    "status_code": 0,
    "status_msg": "success"
  }
}
```

**字段说明：**
- `voice_id`：被删除的音色 ID。
- `created_time`：该音色生成请求提交的时间（格式 `yyyy-mm-dd`），非首次调用生效激活时间。
- `base_resp.status_code`：0 表示删除成功，非 0 见下方错误码。

## 错误码（base_resp.status_code）

| 状态码 | 说明 |
|--------|------|
| 0 | 删除成功 |
| 2013 | 输入参数信息不正常 |
