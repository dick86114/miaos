# 妙生客户端全功能说明

> 用途：提供给 UI 设计 Agent，作为 macOS 客户端与原生 Android 客户端的功能设计依据。  
> 功能基线：以当前 macOS 版本为主要基线，并补充第一阶段 Android 客户端必须具备的平台能力。  
> 本文只描述功能、内容、操作、状态和业务规则，不规定颜色、字体、尺寸、间距、组件样式或具体布局方案。

---

## 1. 产品定位

妙生是一款本地运行的 AI 图片生成与创作管理工具，主要解决以下需求：

- 快速输入提示词并生成图片。
- 使用参考图片进行图生图或连续迭代。
- 将同一创作主题组织成项目，并保留提示词、模型和图片的版本关系。
- 统一查询所有快速生图记录和项目图片。
- 查看本地创作统计。
- 管理多个 AI 供应商、API 地址、API Key 和模型。
- 在 macOS 与 Android 之间安全迁移供应商配置。

产品不要求登录账号，不依赖妙生业务服务端。图片、项目、历史记录和供应商配置均以本地数据为主，生图请求由客户端直接发送给用户配置的供应商。

## 2. 客户端范围

### 2.1 macOS 客户端

macOS 客户端是完整功能基线，包含：

- 快速生图。
- 项目与版本树。
- 历史查询与统计分析。
- 图片详情和预览。
- 供应商及模型管理。
- 默认模型和主题设置。
- 加密配置导出。
- 局域网二维码配对服务。
- 应用版本和更新检查。

### 2.2 Android 客户端

Android 客户端应复刻核心创作、项目、历史和供应商能力，同时承担移动端特有职责：

- 导入 macOS 导出的加密配置文件。
- 扫描 macOS 提供的一次性局域网二维码。
- 在 Android Keystore 保护的本地存储中保存 API Key。
- 从 Android 设备直接请求供应商。
- 使用系统分享面板分享图片。
- 保存图片到系统相册。
- 使用 WorkManager 管理可恢复的生成任务。

### 2.3 当前不属于第一阶段的功能

- 用户账号与登录。
- 云端数据同步。
- S3 自动同步。
- 妙生服务端代理生图。
- 多人协作。
- 视频生成；可以保留视频模型配置概念，但当前不提供视频生成入口。

## 3. 核心业务对象

### 3.1 供应商

每个供应商包含：

- 唯一标识。
- 供应商名称。
- API 类型。
- API 地址。
- API Key 是否已配置。
- 支持的能力：生图、文本、视频。
- 图像模型列表。
- 文本模型列表。
- 视频模型列表。
- 每个模型的启用或停用状态。

当前支持的供应商类型包括：

- Grsai。
- Aiping。
- Agnes AI。
- OpenAI 兼容接口。
- DeepSeek 等文本模型接口。
- 自定义兼容供应商。

### 3.2 快速生图记录

每条快速生图记录包含：

- 图片。
- 提示词。
- 供应商。
- 模型。
- 图片比例。
- 图片质量。
- 生成时间。
- 唯一记录标识。

### 3.3 项目

每个项目包含：

- 项目名称。
- 项目描述。
- 创建时间与最后更新时间。
- 项目封面图片。
- 当前选中的版本。
- 一个或多个根版本和分支版本。

### 3.4 项目版本

每个版本包含：

- 版本名称。
- 提示词。
- 供应商和模型。
- 创建时间。
- 该版本生成的图片列表。
- 父版本标识。
- 派生时使用的父图片标识。
- 是否为根版本或派生分支。

### 3.5 生成任务

生成任务包含：

- 任务来源：快速生图或项目生图。
- 提示词、供应商、模型和生成参数。
- 可选参考图片。
- 所属项目和版本。
- 任务状态。
- 失败原因。
- 生成结果。

任务状态至少包括：

- 等待中。
- 生成中。
- 已完成。
- 失败。
- 已取消。

## 4. 全局功能与规则

### 4.1 导航

客户端需要提供以下核心工作区入口：

1. 快速生图。
2. 项目。
3. 历史与统计。
4. 供应商。
5. 设置。

macOS 可以将“供应商”作为设置中的子页面；Android 可以提供独立供应商入口。无论采用哪种导航结构，功能范围必须一致。

### 4.2 本地数据

- 项目、版本、历史和设置保存在本地。
- 应用关闭或页面切换后，已保存的数据仍需恢复。
- 不应将 API Key 写入普通项目数据、历史数据、Room 普通字段或日志。
- 删除项目或历史记录时，需要明确告知删除范围。
- 本地数据读取失败、记录不存在或文件丢失时，需要提供可恢复的错误状态。

### 4.3 API Key 安全

- macOS 使用系统安全存储保存 API Key。
- Android 使用 Android Keystore 保护 API Key。
- 编辑已有供应商时不得直接回显已保存的 API Key。
- API Key 输入为空时，应保留原有密钥，而不是覆盖为空。
- 删除供应商时同时删除对应的安全密钥。
- 错误信息和持久化任务失败信息必须对 API Key、Bearer Token 等内容脱敏。

### 4.4 通用反馈状态

所有会发起异步操作的功能都应覆盖：

- 默认状态。
- 加载或处理中状态。
- 成功状态。
- 失败状态。
- 无数据状态。
- 禁用状态。
- 用户取消状态。

关键操作需要明确反馈，例如：生成开始、加入队列、保存成功、复制成功、连接失败、导入失败、删除完成等。

### 4.5 确认类操作

以下操作必须进行二次确认或明确告知影响范围：

- 删除项目。
- 删除版本及其所有下游分支。
- 删除图片。
- 批量删除历史记录。
- 删除供应商及其 API Key。
- 导入配置并覆盖或更新本地配置。

## 5. 快速生图页面

### 5.1 页面目标

让用户以最少步骤完成提示词输入、模型选择、生成任务提交和结果查看。

### 5.2 提示词输入

页面需要提供：

- 多行提示词输入。
- 输入为空时阻止提交并提示用户。
- 自动恢复上一次使用的提示词和生成设置。
- 从图片详情“再次生成”返回时，自动带入对应提示词和生成参数。

### 5.3 参考图片

用户可以：

- 选择本地图片作为参考图。
- 查看当前已选择的参考图。
- 移除参考图。
- 有参考图时将任务识别为图生图。
- 无参考图时执行文生图。

需要处理：

- 图片文件不可读取。
- 文件已被删除。
- 图片格式或大小不受支持。
- 当前模型不支持图生图。

### 5.4 长文本导入

用户可以选择文本文件，将文件内容填入提示词输入区。

需要处理：

- 文件不可读取。
- 内容为空。
- 内容过长。
- 用户取消选择。

### 5.5 提示词辅助

提供以下辅助操作：

- 随机提示词：从本地预设中选择一条提示词填入输入区。
- 优化提示词：使用默认文本模型或已配置文本供应商优化当前提示词。

优化提示词时：

- 必须先有有效提示词。
- 必须存在已启用的文本模型和 API Key。
- 优化期间避免重复提交或修改冲突。
- 成功后将优化结果写回输入区。
- 失败时保留原始提示词。

### 5.6 模型与参数

用户需要选择或确认：

- 供应商。
- 已启用的图像模型。
- 图片比例。
- 图片质量。
- 单次生成数量，支持 1 至 4 张。

规则：

- 默认使用系统设置中的默认生图模型。
- 如果上次选择仍然有效，可优先恢复上次选择。
- 切换供应商后，只显示该供应商已启用的模型。
- 模型不可用或供应商已删除时，不允许提交任务。
- 自定义比例或质量值进入页面时不能被预设值静默覆盖。

### 5.7 提交生成

提交前验证：

- 提示词不为空。
- 已选择有效供应商。
- 已选择有效且启用的图像模型。
- API 地址有效。
- 需要密钥的供应商已经配置密钥。
- 图生图任务具有可读取的参考图片。

多张生成需要拆分为独立任务，并保留同一批次关系。

### 5.8 生成队列

页面显示当前快速生图任务，并区分：

- 等待中任务。
- 正在生成任务。
- 已完成任务。
- 失败任务。
- 已取消任务。

任务操作：

- 取消单个尚未完成的任务。
- 取消所有尚未开始的快速任务。
- 失败或取消后重新加入队列。
- 查看失败详情。
- 从队列视图移除已完成、失败或已取消的终态记录。

移除终态任务只移除队列记录，不删除已经生成的历史图片。

### 5.9 快速生图结果与最近历史

生成成功后，用户可以：

- 查看图片预览。
- 打开大图查看。
- 保存图片。
- 查看图片详情。
- 复制提示词。
- 再次生成。

快速历史按时间倒序展示，并支持分页。新任务完成后应优先让用户看到新结果。

### 5.10 空状态与异常状态

- 没有供应商时，引导用户前往供应商设置或配置迁移。
- 没有任务时，不显示无意义的任务区。
- 没有历史时，说明生成成功后会自动保存。
- 生成失败时，保留任务参数和可重试入口。

## 6. 项目列表页面

### 6.1 页面目标

管理不同创作主题，让每个主题拥有独立的提示词版本和图片演进关系。

### 6.2 项目列表

每个项目需要展示以下业务信息：

- 项目名称。
- 项目描述。
- 项目封面；未设置封面时可使用项目内最新图片作为回退。
- 根版本数量或版本数量。
- 项目图片数量。
- 当前版本使用的模型。
- 最近更新时间。

### 6.3 搜索

支持按以下内容搜索：

- 项目名称。
- 项目描述。

无匹配结果与从未创建项目需要使用不同文案和操作逻辑。

### 6.4 新建项目

新建项目需要填写或选择：

- 项目名称，必填。
- 项目描述，可选。
- 初始提示词，可选。
- 供应商。
- 图像模型。

规则：

- 没有可用图像供应商或模型时，不允许创建，并引导到供应商配置。
- 创建项目时自动建立第一个根版本。
- 初始提示词为空时，仍允许创建空白项目。
- 创建成功后进入对应项目工作台。

### 6.5 项目操作

用户可以：

- 进入项目。
- 修改项目名称和描述。
- 删除项目。

删除项目时需要说明会删除：

- 项目记录。
- 项目内全部版本。
- 项目图片历史记录。

## 7. 项目工作台页面

### 7.1 页面目标

围绕一个项目持续生成图片，并以版本树方式保留提示词和参考图片的演进过程。

### 7.2 项目信息

提供：

- 返回项目列表。
- 项目名称和描述。
- 项目设置入口。
- 项目统计摘要，例如版本数量、分支数量和图片总数。

### 7.3 版本树

版本树需要表达：

- 一个或多个根版本。
- 每个版本的父子关系。
- 当前选中的版本。
- 版本名称。
- 提示词摘要。
- 图片数量。
- 最近生成时间或版本创建时间。

用户可以：

- 切换当前版本。
- 查看根版本与所有派生分支。
- 删除一个版本及其全部下游版本。

规则：

- 删除当前版本后，需要自动选择仍存在的有效版本。
- 项目至少需要保留一个可用根版本；如果产品允许删除最后一个版本，则必须立即提供新建根版本入口。
- 版本树中不存在的目标版本应回退到项目当前版本。

### 7.4 当前版本创作区

当前版本可编辑或选择：

- 版本提示词。
- 供应商。
- 图像模型。
- 图片比例。
- 图片质量。
- 单次生成数量。
- 可选参考图片。

支持：

- 随机提示词。
- 提示词优化。
- 选择本地参考图。
- 移除参考图。
- 提交生成任务。

### 7.5 根版本保护规则

当根版本已经产生图片后，如果用户修改提示词、模型或参考图再生成：

- 不应直接覆盖原根版本的创作上下文。
- 应自动创建新的根版本，并把新生成任务归属到新根版本。

如果根版本尚未产生任何图片，则可以直接更新当前根版本并生成第一张图片。

### 7.6 分支版本规则

派生分支时：

- 用户从父版本已生成的图片中选择一张作为参考图。
- 新版本记录父版本和父图片。
- 新版本继承父版本的提示词、供应商和模型，可在后续继续修改。
- 父版本没有图片时不能派生。
- 父图片已被删除时不能继续执行依赖该图片的图生图任务。

### 7.7 项目生成队列

项目内任务需要显示：

- 当前所属版本。
- 提示词和模型。
- 任务状态。
- 失败原因。
- 结果图片。

任务操作与快速生图一致：取消、重试、查看失败详情和移除终态记录。项目被删除或版本在网络请求期间被删除时，任务不得重新创建已删除的数据。

### 7.8 当前版本图片列表

每张图片包含独立的生成元数据，即使版本之后被修改，图片详情仍使用生成时的提示词、供应商、模型、比例和质量。

用户可以：

- 打开图片预览。
- 保存图片。
- 复制提示词。
- 删除图片。
- 设置为项目封面。
- 基于该图片派生分支。

删除图片时：

- 如果图片是项目封面，需要取消封面绑定。
- 如果图片已有下游分支，需要向用户说明分支依赖关系，避免无提示地破坏版本链。

### 7.9 项目设置

用户可以修改：

- 项目名称。
- 项目描述。

项目名称不能为空。保存后项目列表和工作台应同步更新。

### 7.10 项目不存在状态

当项目已被删除或路由指向无效项目时：

- 告知用户项目不存在。
- 提供返回项目列表的入口。
- 不显示失效的生成或删除操作。

## 8. 历史与统计页面

页面包含两个功能区域：

1. 历史记录查询。
2. 本地统计分析。

### 8.1 历史记录范围

统一历史包含：

- 快速生图图片。
- 项目内生成图片。

所有记录按生成时间倒序排列。

### 8.2 搜索与筛选

支持：

- 搜索提示词。
- 搜索模型。
- 搜索供应商。
- 搜索项目名称。
- 按来源筛选：全部、快速生图、项目生图。
- 选择项目来源后，可进一步筛选具体项目。

搜索或筛选变化后回到第一页。筛选结果减少时，当前页码需要自动收敛到有效页。

### 8.3 历史分页

- 历史记录分页加载。
- 当前规则为每页 24 条。
- 提供上一页、下一页、当前页、总页数和总记录数。
- 空结果仍保持稳定的第一页状态。

### 8.4 历史记录操作

单条记录支持：

- 打开图片预览。
- 保存图片。
- 复制提示词。
- 再次生成。
- 快速记录进入图片详情。
- 项目记录跳转到对应项目和版本。
- 删除记录。

### 8.5 批量管理

用户可以进入批量管理模式：

- 跨分页选择记录。
- 查看已选择数量。
- 取消批量模式。
- 删除所选记录。

批量删除需要二次确认，并根据记录来源删除快速历史或项目图片。分页切换不应丢失已选择项。

### 8.6 历史空状态

需要区分：

- 本地从未产生过图片。
- 当前搜索或筛选条件没有匹配结果。
- 项目筛选指向已删除项目。

### 8.7 统计分析

统计全部本地历史记录，不上传图片或提示词。

统计内容包括：

- 图片总数。
- 今日生成数量。
- 本周生成数量。
- 项目数量。
- 近 30 天生成趋势。
- 快速生图与项目生图的来源占比。
- 常用模型排行。
- 常用提示词或提示词关键词统计。
- 活跃日期热力图。
- 峰值日期和峰值数量。

统计无数据时应明确显示本地暂无生成记录，不模拟网络加载状态。

## 9. 图片预览与图片详情

### 9.1 通用图片预览

从快速生图、项目和历史记录打开图片时，预览应支持：

- 查看完整图片。
- 查看提示词。
- 查看供应商、模型、比例、质量和生成时间。
- 项目图片查看所属项目和版本。
- 项目图片查看版本链或派生路径。
- 保存图片。
- 复制提示词。
- 跳转到所属项目。
- 关闭预览并返回原触发位置。

### 9.2 放大查看

- macOS 支持进入全屏或沉浸式大图查看。
- 支持缩放和平移。
- Android 支持双指缩放。
- 退出放大后返回原图片预览，不丢失当前页面状态。

### 9.3 图片详情页面

快速历史图片可进入独立详情页，展示：

- 图片。
- 可编辑的提示词文本。
- 供应商。
- 模型。
- 尺寸与比例。
- 质量。
- 生成时间。

操作：

- 保存图片。
- 删除图片。
- 复制提示词。
- 使用当前编辑后的提示词再次生成。
- 返回历史页面。

记录不存在时需要提供返回历史页面的入口。

## 10. 供应商管理页面

### 10.1 供应商列表

列表需要展示：

- 供应商名称。
- API 类型。
- 已启用模型数量。
- 是否尚未配置模型。

支持：

- 选择供应商查看与编辑。
- 新增供应商。
- 无供应商时进入新增流程。

### 10.2 新增或编辑供应商

基础字段：

- 供应商名称。
- API 类型。
- API 地址。
- API Key。
- 支持能力：生图、文本、视频。

规则：

- 供应商名称不能为空。
- API 地址需要进行协议、格式和安全校验。
- 生产接口默认要求 HTTPS；仅明确允许的本地调试地址可使用 HTTP。
- API 地址不得包含用户名、密码、片段或隐式密钥信息。
- 已保存的 API Key 不回显。
- 输入新 API Key 时使用新值进行连接测试；未输入时使用本地已保存密钥。

### 10.3 API 类型预设

切换 API 类型时可以自动提供对应默认地址和默认能力，但不能静默覆盖用户已经填写的自定义地址。

### 10.4 连接测试

用户可以在保存前或编辑时测试连接。

测试结果需要区分：

- 测试中。
- 连接成功。
- 认证失败。
- 地址错误。
- 网络失败。
- 供应商返回异常。

部分供应商可能使用余额接口或最小测试请求验证认证状态。界面需要明确提示测试是否可能产生最小请求。

### 10.5 模型管理

按能力分类管理：

- 图像模型。
- 文本模型。
- 视频模型。

每一类支持：

- 从供应商获取模型列表。
- 手动添加模型。
- 启用或停用模型。
- 移除模型。
- 显示已启用数量和总数量。

规则：

- 开启某项供应商能力后，该分类至少需要一个启用模型才能保存。
- 文本专用供应商可以不配置图像模型。
- 图像和文本模型均为空时不允许保存无效供应商。
- 模型获取失败时保留现有模型列表。

### 10.6 保存与删除

保存供应商时：

- 供应商元数据和 API Key 需要以事务方式更新。
- 元数据保存失败时回滚密钥变更。
- 密钥保存失败时不能声称供应商保存成功。

删除供应商时：

- 二次确认。
- 删除供应商元数据。
- 删除对应安全密钥。
- 已有历史图片保留，但使用该供应商的旧版本再次生成前需要重新选择可用供应商和模型。

### 11.1 主题模式

- 深色。
- 跟随系统。

切换后立即生效，并在重新启动后保持。

### 11.2 默认模型

用户可以设置：

- 默认生图供应商和模型。
- 默认文本供应商和模型。

## 13. macOS 与 Android 配置迁移

### 13.1 加密配置文件

macOS 可以导出 `.miaos` 加密配置文件，内容包括：

- 供应商元数据。
- 模型列表和启用状态。
- 默认模型设置。
- 主题偏好。
- 对应供应商的 API Key。

不包括：

- 历史图片。
- 项目。
- 图片缓存。
- 日志。
- 窗口状态。
- 本机绝对路径。

导出时：

- 用户设置导出密码。
- 密码不能为空。
- 文件由用户选择保存位置。
- API Key 只存在于加密 payload 中。

### 13.2 Android 文件导入

Android 导入流程：

1. 选择 `.miaos` 文件。
2. 输入 macOS 导出时使用的密码。
3. 解密并校验格式和版本。
4. 显示导入摘要。
5. 用户确认后才写入本地。

导入摘要包括：

- 供应商数量。
- 供应商名称和类型。
- 各供应商图像、文本模型数量。
- 将导入的 API Key 数量。
- 默认模型和主题信息。

摘要绝不显示 API Key 内容。

错误情况：

- 密码错误。
- 文件被篡改。
- 文件格式错误。
- 配置版本高于客户端支持版本。
- API 地址不安全。
- 导入过程中存储失败。

### 13.3 局域网二维码配对

macOS 发起配对时：

- 用户设置加密密码。
- 客户端生成一次性随机 token。
- 启动临时局域网 HTTP 服务。
- 生成二维码。
- 生成 6 位配对确认短码。
- 显示过期状态和停止配对操作。

Android 扫码后：

1. 校验二维码是否为合法局域网地址。
2. 显示与 macOS 相同的 6 位短码。
3. 用户人工确认两端短码一致。
4. 输入导出密码。
5. 读取加密配置。
6. 显示导入摘要。
7. 用户确认后写入 Android 本地。

安全规则：

- 二维码不包含 API Key 或配置明文。
- 短码不包含 API Key，也不能替代一次性 token。
- 配对默认 5 分钟过期。
- 第一次成功读取后立即关闭临时端口并撤销 token。
- 用户停止、页面关闭、窗口关闭或应用退出时撤销临时服务。
- 错误 token 不消耗有效会话。
- 已过期或已消费会话不能再次读取。

## 14. Android 专属系统能力

### 14.1 本地生成队列

- 使用 WorkManager 调度任务。
- 任务串行执行，避免同时请求多个供应商造成重复扣费或状态混乱。
- 等待网络连接后再执行。
- 应用进程重启后恢复未完成任务。
- 非幂等生图请求失败后不自动无限重试，避免重复扣费；由用户决定是否重试。

### 14.2 保存到相册

- Android 10 及以上使用系统媒体库接口保存。
- Android 9 及以下按系统要求申请旧版存储权限。
- 权限被拒绝、文件不存在或写入失败时提供明确反馈。
- 保存成功后图片可在系统相册中查看。

### 14.3 系统分享

- 通过系统分享面板分享图片。
- 使用受控的临时读取权限，不暴露应用私有文件路径。
- 图片不存在或没有可处理分享的应用时提供错误反馈。

### 14.4 系统返回与状态恢复

- 从项目内生图返回项目详情。
- 从项目详情返回项目列表。
- 普通一级工作区按平台规则处理返回。
- 旋转屏幕或应用短暂进入后台后，关键页面状态、筛选条件和任务状态应恢复。
- 密码、API Key 和一次性敏感输入不应被不必要地持久化。

## 15. 错误、空状态和边界状态清单

设计时至少需要覆盖以下状态：

### 15.1 全局

- 页面加载失败。
- 本地数据损坏。
- 本地存储不可写。
- 网络不可用。
- 操作被用户取消。

### 15.2 生图

- 没有供应商。
- 没有启用的图像模型。
- API Key 未配置。
- 提示词为空。
- 参考图不存在。
- 任务等待中、生成中、失败、取消、完成。
- 没有快速历史。

### 15.3 项目

- 没有项目。
- 搜索无结果。
- 项目不存在。
- 版本不存在。
- 当前版本没有图片。
- 父参考图片已删除。
- 删除版本会影响下游分支。

### 15.4 历史

- 没有任何历史记录。
- 搜索无结果。
- 来源筛选无结果。
- 项目筛选指向已删除项目。
- 批量管理未选择任何记录。
- 删除后当前页越界。

### 15.5 供应商

- 没有供应商。
- 未选择供应商。
- API 地址不合法。
- 连接测试失败。
- 获取模型失败。
- 能力已启用但没有启用模型。
- API Key 保存、删除或回滚失败。

### 15.6 配置迁移

- 文件选择取消。
- 密码为空或错误。
- 文件损坏或被篡改。
- 未知版本。
- 二维码非法。
- 短码不一致，由用户取消。
- 会话过期。
- 配置已被另一设备读取。
- 读取过程中断网。

## 16. 设计 Agent 交付要求

设计 Agent 应基于上述功能，分别输出 macOS 与 Android 的完整客户端方案，并满足：

- 每个核心页面都有正常、加载、空、错误和不可用状态。
- 所有危险操作都有确认过程和影响范围说明。
- 快速生图、项目生图、队列、历史记录之间的数据关系清晰。
- 项目版本树能表达根版本、父子关系、参考图片和当前版本。
- 供应商配置能表达 API 类型、能力分类、模型启用和安全密钥状态。
- macOS 导出与 Android 导入、扫码配对流程完整闭环。
- 不把 API Key、导出密码或一次性 token 当作普通可展示数据。
- Android 与 macOS 功能一致，但交互应遵循各自平台习惯。
- 不自行增加登录、云同步、服务端代理、会员付费或社交功能。
