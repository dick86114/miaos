# 提示词优化霓虹粒子能量场设计

## 目标

在提示词优化请求进行期间，以覆盖整个输入框的霓虹粒子能量场替换底部频谱扫过动效。效果应体现“AI 正在处理”，但不遮挡文字、不影响输入框尺寸或页面流畅度。

## 适用范围

- 快速生成页的提示词输入框；
- 项目工作台的版本提示词输入框；
- 仅在输入框带有 `is-optimizing` 状态时显示。

## 视觉与交互

输入框内部增加独立、不可交互的效果层。该层由低密度彩色粒子、柔和光晕和边缘流光组成：青蓝、紫色和少量粉色粒子以不同节奏漂浮，边缘渐变光带缓慢环流。文本和光标始终位于动效之上；输入框在优化时仍为只读。

动效开始时快速淡入，优化成功或失败时在既有清理逻辑中淡出并移除。保留优化按钮的旋转反馈和现有 Toast 状态提示。删除现有 `.composer-wave-bar` 及其底部频谱扫过效果。

## 技术方案与性能约束

使用 CSS 多层径向渐变、伪元素和仅合成层属性（`transform`、`opacity`）实现；不使用 Canvas、SVG 滤镜、定时器或 `requestAnimationFrame`。效果层在每个输入框初始化时最多创建一次，并仅通过 class 控制显示，避免优化期间反复创建节点。

在 `prefers-reduced-motion: reduce` 下禁用循环动画，改为静态的低对比彩色边缘和背景光晕，仍保留可见的“处理中”状态。

## 验收与测试

- 两个页面均显示完整输入框范围内的粒子效果，不再出现底部频谱条；
- 动效层不接收鼠标、键盘或文本选择事件；
- 优化结束、失败及路由卸载后，效果层和状态均正确清理；
- 增加 DOM/源码契约测试，验证两页接入、旧频谱结构移除及减少动态效果降级；
- 运行 `pnpm check`，并在 Electron 本地窗口中手动验证快速生成页与项目工作台。
