# 统一生成历史、预览与批量管理设计

## 目标

统一快速生图、项目生图和全量历史的结果展示。快速生图页在输入框下连续展示当前队列与自身持久化历史；历史记录页合并全部来源并支持分页、筛选、批量删除。所有图片入口使用同一套弹窗大图预览与全屏缩放体验。

## 导航与页面命名

保留现有 Hash 路由，修改侧边栏文案为：快速生图、我的项目、历史记录、系统设置。对应路由仍为 `#/generate`、`#/projects`、`#/history`、`#/settings`，避免破坏已有链接。

## 快速生图结果区

移除独立大图主展示区。输入框下方按以下顺序展示：

1. 生成中：仅显示 queued 与 running 的快速生图任务；
2. 快速生图历史：读取持久化 `state.history`，按生成时间倒序显示图片卡片。

快速生图历史默认每页 12 张，提供上一页、下一页、当前页/总页数。完成任务写入持久化历史后立即刷新该列表；队列完成卡片不再作为第二套历史来源。无队列且无快速历史时显示空状态。

## 全量历史记录

历史记录页把快速历史和项目版本图片标准化为统一记录，按 `createdAt` 降序合并分页。默认每页 24 张。每条记录包含稳定复合 key、来源、图片路径、提示词、供应商、模型、比例、质量、时间；项目图片额外包含 `projectId`、`projectName`、`versionId`、`versionName` 与 `imageId`。

页面提供关键词搜索与来源筛选（全部、快速生图、项目生图）。筛选与搜索变化后回到第 1 页。卡片复用项目画廊的布局：图片区域、来源标签、悬浮操作、模型/参数/时间信息，项目图片额外展示项目归属。

## 统一图片预览

提取共享预览组件，供快速生图、项目画廊和历史记录调用。第一层为弹窗：右上角关闭、点击遮罩关闭、Escape 关闭；左侧展示大图，右侧展示提示词和生图参数，底部提供保存与复制提示词。项目图片额外提供“前往项目对应图片”。

“前往项目对应图片”跳转到 `#/project/<projectId>?version=<versionId>&image=<imageId>`。路由解析参数后选中对应版本并自动打开该图片。

在弹窗内再次点击图片进入沉浸式全屏查看层：占满视窗、再次点击外部或 Escape 返回/关闭；支持滚轮缩放、拖拽平移、缩放复位。缩放层不得修改图片文件或历史数据。

## 批量删除

历史记录页通过“批量管理”切换进入选择模式。卡片出现复选框，底部固定操作条显示选择数量、取消和“删除所选”。删除前展示来源分类与数量的二次确认。

快速生图记录删除对应 `state.history` 条目；项目生图记录删除对应项目版本中的图片。删除完成后刷新合并记录、保持有效页码并清空选择。未选中记录时删除按钮禁用。批量模式不影响普通单图预览、保存或项目跳转。

## 可访问性、性能与边界

- 所有按钮具备明确中文 `aria-label` 或可见文字；弹窗打开后焦点进入弹窗，关闭后恢复触发元素焦点。
- 弹窗与全屏层均使用 Escape 和点击遮罩关闭；全屏层阻止背景页面滚动。
- 分页只渲染当前页卡片，保持稳定 key 和事件委托；不为每张卡片重复注册监听器。
- 项目历史批量删除沿用当前项目图片删除语义；确认框明确提示删除会影响该项目版本的图片记录。
- 不引入第三方依赖；使用原生 DOM、Hash 路由、现有状态存储与 CSS 动画体系。

## 验收与测试

- 侧边栏四项文案与路由高亮正确；
- 快速生图页可分页查看全部持久化快速历史，完成任务即时出现；
- 全量历史按时间混排快速与项目图片，搜索、来源筛选和分页正确；
- 任意入口打开的弹窗预览信息与操作一致；项目跳转能定位版本与图片；
- 全屏层支持缩放、平移、关闭与焦点恢复；
- 批量删除按来源正确删除数据并更新分页；
- 运行 `pnpm check`，并在 Electron 中覆盖快速、项目、历史三条真实交互路径。
